# v3 制作与验证边界

> 规范 3.1 起，新图标包给每个图标写 `"fit": "canvas"`，整张画布放进系统图标的格子，见[图标包规范 3.1](ICON-PACK-SPEC.zh-CN.md)与[3.1 验证记录](SPEC-3.1-VALIDATION.zh-CN.md)。下文的“可见高度”规则只适用于不写 `fit` 的图标。

schema负责字段提示，Python工具负责有界ZIP预检。Android的`IconManagementManifest/IconManagementArchive/IconAssetDecoder/IconVectorAsset/IconAnimationAsset`及Repository事务仍为最终准入依据。不得把schema或Pillow通过称为Android安全等价、RAR验证、Skia视觉或OEM动画播放通过。

桌面工具验证ZIP中央目录、普通文件类型、数量、路径/大小写冲突、单文件与展开预算；在内存中有界读取，不向任意归档路径解压，不运行包内代码。RAR不在工具能力内。

JSON拒绝重复键、无效UTF-8/孤立代理字符、NaN/Infinity、超限深度、超长数值及未知字段。manifest交叉检查格式、SHA-256、已登记状态和精确动态静态端点。未知安全角色只成为候选，不能注册宿主。

PNG逐块校验CRC，拒绝APNG、未知关键块、重复IHDR、尾随数据；只把图形块交给Pillow并检查实际透明像素。XML拒绝实体/引用/处理指令，限制标签、Android属性、节点深度、路径参数及弧线标志。XML节点最多128、深度最多8层、路径字符总量≤65536、单路径命令≤2048、数值≤8192且绝对值≤4096；根Alpha、路径Alpha独立，桌面工具不代替Android图层合成结果。

Lottie仅接受shape layer与7种图形节点。图层≤16、形状≤256、组深度≤8；关键帧每属性≤64且总量≤256，路径累计顶点≤2048。大小、半径、线宽不能为负。画布1–256px，帧率1–60，稳定切换≤800ms、瞬态≤1500ms，时间严格递增且至少一项属性真正变化。禁止表达式、文字、图片、效果、mask、父层、3D及时间重映射。

Python/ElementTree/Pillow与Android/XmlPullParser/Skia实现不同；Unicode计数、浮点精度、路径栅格化及系统库差异仍由生产端决定。工具可能更严格，但不能放宽App合同。真实颜色、Alpha、快切、末态、回收和恢复另行实机检查。

## beta95/code188 静态可见高度规则

Android在后台完成PNG解码或受限XML栅格化后扫描可见像素，边界条件为`alpha > 0`，不丢弃半透明外缘。绘制使用缓存边界：先匹配原生图形区域的高度，再保持宽高比居中；如果可见宽度超过可用区域，按宽度限制等比缩小。空白或坏边界保留原生。原始文件与位图像素不裁改，只有绘制源矩形和预览显示区域归一；OEM View尺寸、原生布局及Canvas变换保留。

扫描与解码不进入热绘制，绘制复用裁剪矩形和目标矩形。颜色模式与透明度计算独立于几何归一，原色Alpha不因此被额外相乘。桌面预检没有执行Android栅格化或宿主绘制，不能把其通过解释为可见高度或透明度已实机验收。

beta96/code189新增的`cellular.stacked_primary.*`与`cellular.stacked_secondary.*`是例外：二者各保留共同19×16逻辑画布，上柱下点按完整画布叠合，不对每行独立裁边或高度归一。PNG示例为114×96；XML栅格化后的留白连同逻辑宽高保留，预览也采用共同画布。仅这12个已登记角色使用该规则，单排蜂窝与其他静态角色不变。

本版没有对Lottie逐帧计算或套用可见边界，也没有改OEM动画View尺寸。逐帧裁边会令图形尺寸跳动，静态末态边界也不能证明动画中间帧不会越界。动态图形需自行保证画布、端点与中间帧的一致性，并在真实宿主验证；静态归一检查不替代这项验证。

`tools/check_validator.py`以真实原创包为正例，逐项构造坏摘要、CRC、路径、XML、JSON、状态、时间及端点负例。修改资源时同步摘要，避免旧摘要错误掩盖深层检查缺失。负例仅在临时目录产生。

角色快照来自2026-10-18的生产Registry：beta96/code189为189角色、91目标，增加双排信号两个目标；beta94/code187与beta95/code188均为177角色、89目标。格式仍为v3，但含双排新角色的包要求beta96或更新版本，旧版会将其识别为已登记蜂窝目标的非法状态并拒绝整包；旧v3包仍可导入新版。全部素材覆盖只证明图案存在；cast、controls、wallet及品牌/自定义内容边界仍保留原生，不等于整个控制中心或全部动画实机通过。
